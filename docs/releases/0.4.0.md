# 0.4.0

Minor release of `bespokelabs-sandbox`, based on main at
`a99636b03d4fc878a529f4be17adfa977f33d2c5`, compared with `v0.3.0`.

- Add the Boxd backend, available through `bespokelabs-sandbox[boxd]`
  (`boxd>=0.2.20`), including filesystem, session, and network-policy support.
- Add the optional Monty Python sandbox backend (`[monty]`).
- Add sandbox listing by label for Daytona and Modal.
- Add lifecycle telemetry, live sandbox resource sampling and dashboard charts,
  and agent token usage with labeled model costs.
- Add first-class Grok and Codex harness support and refresh observability and
  control documentation.
- Harden image-build workflow input handling and improve resource sampling,
  dashboard rendering, and closed-runtime checks.

The existing `bespokelabs.sandbox` imports and namespace packaging are unchanged.
Provider SDKs remain optional; the core dependency remains Pydantic. This release
contains only changes already merged into the main commit above, plus the release
version, these notes, and a network-policy test fixture update for Modal 1.6.3's
internal implementation layout; it does not include unmerged transition-policy work.
